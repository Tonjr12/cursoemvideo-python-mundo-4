# 🐍 Python 3 - Mundo 4: Programação Orientada a Objetos (POO)

Repositório com todos os exercícios, desafios e códigos de aula desenvolvidos durante o **Mundo 4** do curso de Python 3 do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor **Gustavo Guanabara**.

---

## 🎯 Sobre o Mundo 4
- **Carga Horária:** 40 Horas
- **Status:** Em Andamento ⏳
- **Conteúdo Programático:**
  - Fundamentos da Programação Orientada a Objetos (POO)
  - Classes, Instâncias e Atributos de Classe vs Atributos de Instância
  - Métodos Especiais (Dunder methods: `__init__`, `__str__`, `__repr__`)
  - Encapsulamento, Getters, Setters e Properties (`@property`)
  - Herança Simples e Múltipla (`super()`)
  - Polimorfismo e Sobrecarga de Métodos
  - Bibliotecas e Recursos Modernos (Terminal interativo com biblioteca `rich`)
